# BizBill release notes

The first `## ` section is published with the next release (update.json and
the GitHub Release page). Add a new section at the top for every release.

## 3.5

- New secure Android app: hardened WebView, local-only data, no tracking
- Payment In / Payment Out with up to 4 bill attachments (photo / PDF)
- Payment due, overdue and low-stock alerts with optional full-screen alerts
- Notification Center, payment reminder cards (WhatsApp / JPG / PDF)
- Product images, password-protected backups, verified in-app updates
